# MSDesk

Alle deine Computer und dein Handy wie ein einziger Schreibtisch: Bildschirme, Apps, Dateien, Zwischenablage, Kamera, Anrufe, Nachrichten, Maus und Tastatur, geteilt zwischen Mac, Windows, Linux und Android.

Dieses Repository enthält nur die **Releases** von MSDesk: die Installer für jedes System und den Quellcode jeder Version. MSDesk selbst sucht hier nach Updates.

**[⬇️ Zur neuesten Version](https://github.com/mosaleh13/MSDesk-Releases/releases)**

## Was in jedem Release liegt

| Datei | Für |
|---|---|
| `MSDesk-<Version>-arm64.dmg` | macOS, Apple Silicon |
| `MSDesk-<Version>-x64.dmg` | macOS, Intel |
| `MSDesk-Setup-<Version>.exe` | Windows, x64 |
| `MSDesk-Setup-<Version>-arm64.exe` | Windows, ARM64 |
| `MSDesk-<Version>-amd64.deb` | Linux, Debian und Ubuntu |
| `MSDesk-<Version>-x86_64.AppImage` | Linux, jede Distribution |
| `MSDesk-<Version>.apk` und `…-full.apk` | Android |
| `MSDesk-<Version>-source.tar.gz` | der vollständige Quellcode dieser Version |
| `SHA256SUMS.txt` | Prüfsummen aller Dateien |
